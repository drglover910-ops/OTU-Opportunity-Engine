# Chat-first Matrix workspace — v0.11.0

The default screen is now conversation. The sidebar holds New conversation, Opportunities, Ready to review, Career library, Connections and Help. Existing overview, platforms, workspace and developer controls remain under My account & tools. Recent conversations support title/platform filtering, separate persistent threads, rename and a selected-row indicator. The last opened conversation is restored on the same device. Existing conversations are retained as original threads. New thread notes, pinned instructions, AI context/replies and reviewed developer requests are scoped by chat ID. Backups preserve those IDs and restore old backups with null IDs. Moving an opportunity moves its associated conversation metadata too.

The bottom composer stays in view, with normal send and optional writing modes/note saving under Options. Conversation tools hold pinned memory, developer requests and application actions. Main navigation collapses behind a menu on tablet/phone widths. The viewport follows the visual viewport when available so the composer can remain above the mobile keyboard. This was tested through responsive browser fixtures; actual iPad Safari keyboard behavior still benefits from owner confirmation.

PDFs open beside chat on wide screens, with a review sheet on phones. Designed pages are rendered privately as PNGs using pinned pypdfium2 rather than relying on a browser PDF plugin. Previous/next page controls, text editing, AI wording suggestions and reviewed version saving remain available. Original files/master records stay unchanged and changing unsent attachments resets approval. The mobile review sheet uses an inert background, focus handling, a close button and Escape support.

Matrix code rain is a local, decorative Canvas layer using digits, Latin letters and supported halfwidth kana. It ignores input and assistive reading. The target is18 fps on larger screens and12 on phones, with capped pixel density/columns. The saved pause setting and system reduced-motion preference control animation, and hidden pages stop requesting frames. Static rain remains when animation is off. No inference, external animation service, tracking or scheduled AI calls are used for it.

Validation:75 meaningful unittests passed, both JavaScript assets passed syntax checks, and desktop/tablet/phone browser fixtures covered new chat separation, old history, rename/search/reload, paused/reduced/hidden Matrix behavior, rendered PDF content, side review/mobile inert state, revision saving and overflow. The model was mocked for fixture dialogue; no paid inference or client messages were used. Production runtime checks additionally verify both preview endpoints, the Matrix script, thread-list access and mounted storage. Public research is recorded in docs/UI_REFERENCE_RESEARCH.json and design direction in docs/UI_DIRECTION.md.

Dependency: pypdfium2==5.14.0 (PDFium page rendering) is included in requirements.txt and Docker deployment. Existing pip installation of requirements reproduces it; no new credentials or paid services are required.
