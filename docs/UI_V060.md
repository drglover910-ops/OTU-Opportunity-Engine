# Everyday interface — v0.6.0

Home, Find opportunities, My opportunities, Ready to send, and Help are the main navigation. Workspaces, My profile, Connections, and Developer tools are secondary tools.

Contra, public opportunities, past email outreach, and other opportunities have separate workspaces. More workspaces can be added. Each opportunity has a separate conversation, with its own original email threads and notes. Workspace planning is separate from opportunity work. Optional Ask the bot answers use only that workspace or opportunity's context, share that text with Hugging Face, and use the same ten-request daily allowance as AI drafts. Answers cannot send emails or submit applications.

Technical settings and backup restoration require a server-issued developer unlock lasting 30 minutes. The explicit unlock prevents accidental settings changes inside this private single-owner Space; Hugging Face private access remains the authentication boundary. It is not an additional password or a multi-user role system.

Connection checks verify Gmail profile access and saving, and show configured versus previously tested AI writing honestly. Contra account access is not established by creating a workspace or opening its website. The remaining platform step is to sign in on Contra and provide a listing or a supported connection method; credentials must not be pasted into chat.

Deployment may make one small Hugging Face inference check only when configured and never previously successful. The check records its question in the Contra workspace and does not repeat an already recorded attempt. No OpenAI calls, applications, or emails are sent.
