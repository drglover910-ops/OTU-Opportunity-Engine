# v0.12.0 — typing, dictation and fresh applications

The owner's iPad recording showed the shell disappearing behind the Matrix canvas briefly as the keyboard opened, then returning above it. The browser viewport resize handler was resizing the shell without accounting for Safari's viewport pan. The shell now anchors to visualViewport height and offsetTop through a coalesced animation frame, with independent pane scrolling and preventScroll programmatic focus. Inputs use at least 16px and pinch zoom stays available. This is a targeted correction; actual owner-device Safari keyboard behavior remains to be confirmed.

Speak starts browser SpeechRecognition/webkitSpeechRecognition where available. Stop leaves editable text for review; it never sends, invokes AI, records to app storage, or calls a paid transcription API. Browser/vendor speech processing may be online. Listening disables Send and manual input; errors and unsupported browsers offer keyboard dictation guidance. Capture stops on navigation/background; late results cannot write into another conversation. Microphone hardware and Safari permissions cannot be validated by a mocked browser fixture.

Each opportunity offers Generate résumé + cover letter. The existing source-based generator now ranks verified facts against the listing, creates unique opportunity/version filenames and keeps a package attached to that opportunity. Past imported résumés remain available as examples for wording/design reference, not default attachments or factual replacements for the master. No AI calls are needed for package generation. This is deterministic document preparation, not a claim of model-written bespoke content. Owner-reviewed conversational document revisions remain available under existing AI allowances.

The proposal writer no longer automatically attaches a résumé from library search. Attachment choices are limited to that opportunity's prepared documents and portfolios; approval checks reject unrelated résumé/cover-letter files, including previously attached examples. Existing files/history are retained. Generated versions are records of an application, not default sources for future applications. Master source files and confirmed-update controls are preserved.

Validation: 77 unit tests; Chromium desktop/tablet/phone fixture, separate conversations, document revisions and previews; mocked speech start/result/stop and late-result isolation; simulated visual viewport height/pan. No paid inference, microphone capture, client email or platform submission during checks.
